# Criteria

Ortak kriter dili: Valve tarzı ağırlıklı kriterlerin JSON ayrıştırıcısı, doğrulayıcısı ve puanlayıcısı. Sonuç kuralları, diyalog şablonları ve eylem ön koşulları aynı yapıyı kullanır (5.9).

**Yazılacağı hafta:** 2. hafta (plan bölüm 5 ve 12). Şimdilik boş; 1. haftada yalnızca iskelet var.
